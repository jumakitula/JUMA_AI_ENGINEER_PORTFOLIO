A production-ready agent backend

A reusable backend for chat agents. It keeps context across conversations, remembers things long term, and has the safety and monitoring a real deployment needs.

  • FastAPI
  • LangGraph
  • PostgreSQL + pgvector
  • Redis
  • Langfuse
  • Docker
How it works
  • LangGraph runs the conversation as a stateful workflow, with tool calls and human-in-the-loop steps.
  • Long-term memory is stored as vectors in pgvector and retrieved by meaning.
  • The LLM layer works with multiple providers and falls back and retries when one fails.
  • JWT login, rate limiting, caching, and migrations protect the API; Langfuse, Prometheus, and Grafana show what’s happening.

A sales agent that serves many businesses

One deployment powers several shops. Each business gets its own persona, product catalog, and model, and customers can chat on Telegram, WhatsApp, Instagram, or the web.

  • LangGraph
  • FastAPI
  • Telegram
  • WhatsApp
  • Instagram
  • YAML config
How it works
  • A single shared LangGraph workflow handles every tenant; a YAML file defines each business.
  • Channel adapters and webhooks connect each messaging app to the same agent.
  • Tools search products, apply promotions, and find items from a customer’s photo.
  • A provider factory lets each business use a different LLM.

A research team made of agents

A search agent, a fact-checker, and a writer pass work along and return a structured report with confidence levels. It runs serverless on AWS Lambda.

  • LangGraph
  • OpenAI API
  • Serper API
  • Docker
  • AWS Lambda
  • CircleCI
How it works
  • Each agent has one job: find sources, verify claims, or write the summary.
  • Research settings live in configuration, so a new topic needs no code change.
  • Docker packages the app, CircleCI builds it, and Lambda runs it.
